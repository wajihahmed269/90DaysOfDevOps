Day 65 – Terraform Modules: Build Reusable Infrastructure
Overview

Day 65 focused on Terraform modules and reusable infrastructure.

Instead of writing everything inside one large main.tf, infrastructure was separated into reusable modules.

Concepts Used
Concept	Used For
Root Module	Main infrastructure entry point
Child Modules	Reusable infrastructure units
Module Variables	Dynamic module inputs
Module Outputs	Sharing values between modules
Dynamic Blocks	Generating repeated configurations
Registry Modules	Using official Terraform modules
Key Learnings
Built custom EC2 and security group modules
Used module outputs to connect resources together
Created reusable infrastructure components
Used Terraform Registry VPC module
Learned module version pinning
Practiced infrastructure abstraction
