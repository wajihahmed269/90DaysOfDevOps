Day 70 – Variables, Facts, Conditionals and Loops
Overview

Day 70 focused on making Ansible automation dynamic and environment-aware.

Used variables, facts, loops, and conditional logic to build smarter automation workflows.

Concepts Used
Concept	Used For
Variables	Dynamic configuration
group_vars	Group-level configuration
host_vars	Host-level configuration
Facts	System information gathering
Conditionals	Conditional task execution
Loops	Repeated automation tasks
Register	Capturing command output
Key Learnings
Used group and host variables
Gathered system facts dynamically
Applied conditions with when
Automated repetitive tasks with loops
Built server reporting automation
